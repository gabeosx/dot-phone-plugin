# Validation gates

- Offline unit/protocol/control tests use fictional fixtures and no paid services.
- Local package setup must work with each installer's credentials and registration.
- A live test needs the installer's verified routes, bounded approval and retained evidence.
- Mock or replay results do not establish acoustic, carrier or installed-Dots success.
- Report unresolved outcomes and unknown costs honestly.

Historical operator diaries and call evidence belong in private local storage,
not the distributable repository. See docs/LOCAL-SETUP.md and docs/RUNBOOK.md.
